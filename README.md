**Final Project Submission – Code in Place 6**

Anime Picker is a simple desktop application built with Python and CustomTkinter that helps users decide what anime to watch.

Users can add anime titles, remove them, save their list locally, and randomly select one using a built-in picker.  
The app automatically stores data so the list is preserved between sessions.

---

## 🎯 Features

- Add anime to a watchlist  
- Remove anime from the list  
- Random anime selection tool  
- Save list locally to a file  
- Auto-load saved anime on startup  
- Clean and simple GUI using CustomTkinter  

## 🚀 How It Works

1. Enter an anime title in the input box  
2. Click **Add Anime**  
3. Click **Pick Anime** to randomly select one  
4. Click **Save Data** to store your list  
5. Restart the app to automatically load saved anime
